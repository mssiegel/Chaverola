# Questions for the founder

The inbox for unattended runs (README → "Running these unattended"). An agent
that hits a product decision its doc doesn't settle writes the question here,
marks the prompt blocked in its doc, and moves on to the next doc — nobody
guesses product behavior.

Each entry carries the doc and prompt, the context an answerer needs, and the
question. Founder: write your answer right under the question. The next session
folds it into the doc as a "Settled (founder, <date>)" entry, deletes the entry
here, and unblocks the prompt. An empty inbox is the good state — leave the
file in place.

_No open questions._
